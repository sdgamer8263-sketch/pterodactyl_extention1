Arix Theme

Simple & beautiful theme installation guide for Pterodactyl Panel

Made by Mrbeenopro

Prerequisites Check

Ensure you have SSH access to your VPS/Server hosting the Pterodactyl Panel. Log in as root or a user with sudo privileges before starting.

1

Upload Theme Files

Extract your purchased Arix Theme archive and upload the files to your server. Make sure the files are placed directly in the Pterodactyl folder: /var/www/pterodactyl.

2

Install System Dependencies

Update your local package lists and install the common system-level utility tools required for compiling and linking files.

Bash Terminal 
sudo apt update && sudo apt install -y ca-certificates curl git gnupg unzip wget zip
3

Add Node.js v22 Repository & Install

Arix Theme compilation requires Node.js. Add the official NodeSource APT repository for Node.js 22.x and install it on the system.

Bash Terminal 
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg
echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_22.x nodistro main" | sudo tee /etc/apt/sources.list.d/nodesource.list
sudo apt update && sudo apt install -y nodejs
4

Install Yarn & Node Packages

Change directory into your Pterodactyl root path, install the global yarn package manager, and then download all of Pterodactyl's Node.js dependencies.

Bash Terminal 
cd /var/www/pterodactyl
npm i -g yarn
yarn install
5

Run Arix Installer

Execute the theme artisan installer command. Follow the interactive prompts in your terminal to complete the theme installation.

Bash Terminal 
php artisan arix install
6

How to Uninstall (Optional)

If you ever need to uninstall the Arix Theme and restore your original Pterodactyl panel layout, you can execute the uninstall action command.

Bash Terminal 
php artisan arix uninstall
